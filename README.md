# Ludoman Spin — покерный бот для Telegram

Техасский холдем прямо в групповом чате. Работает на Cloudflare Workers +
Durable Objects (бесплатный тариф, без сервера), деплой одной командой.

## Как играть

| Команда | Что делает |
|---|---|
| `/ludoman_spin` | Открывает стол: до 30 секунд на вход по кнопке; если 5 секунд никто не входит и игроков двое и больше, стартует сразу; если за 30 секунд никто не подключился — раздача идёт против бота «Старик Лудоман» |
| `/ludoman_duel @username` | Вызывает конкретного игрока на дуэль 1 на 1, без сбора: раздача начинается сразу, как только адресат нажмёт «Принять» |
| `/ludoman_top` | Кто чаще побеждал |
| `/ludoman_cancel` | Отменить текущую раздачу |
| `/bot_version` | Какая версия задеплоена |

После сбора всем раздаётся по 2 карты, они открыты всем сразу. Рядом с каждым
игроком — процент на победу: на префлопе Монте-Карло (1500 раздач), на флопе
и тёрне точный перебор доборов. Флоп, тёрн и ривер крутятся сами с паузой
4 секунды, перед ривером — барабанная дробь (пауза 6 секунд). Бот
комментирует сильные руки на столе (флеш, фулл-хаус, каре, стрит-флеш),
на вскрытии ставит 🔥 за флеш и старше, 💀 за пустую руку, и отмечает
😱 БЭДБИТ, если игрок с шансами 80%+ на префлопе всё равно проиграл.
Фишек нет, только счёт побед. Если за 30 секунд в одиночную раздачу
никто не зашёл, соперником становится бот «Старик Лудоман» — у него нет
никакой стратегии, ему просто раздаются случайные карты, всё решает
вскрытие, как и с живым игроком. В `/ludoman_top` он не участвует.

Дуэль работает по нику: бот сравнивает `@username` из команды с ником
нажавшего кнопку «Принять вызов». На вызов 60 секунд, потом он сгорает.
Если у адресата нет публичного username в Telegram, дуэль с ним не позвать —
только обычный `/ludoman_spin`.

## Как устроено

- `src/poker.js` — колода, оценка комбинаций и расчёт шансов, чистая логика
- `src/table.js` — Durable Object «стол»: один на чат, хранит лобби, раздачу
  и счёт побед; будильник (alarm) через 30 секунд раздаёт, дальше крутит улицы
- `src/index.js` — worker: проверяет секрет вебхука и передаёт апдейт столу
- `test/run_tests.mjs` — юнит-тесты (`npm test`)
- `test/mock_telegram.mjs` — фейковый Telegram для локального прогона
- `deploy.sh` — тесты, деплой, секреты, регистрация вебхука
- `.secrets` — токен бота и секрет вебхука, в git не попадает

## Темы (форумы)

Если группа — форум с темами (как «Oko Poker Club» с темами General,
Лудки и т.д.), бот сам определяет тему по `message_thread_id` входящего
сообщения и отвечает туда же. Разные темы одного чата ведут независимые
игры — раздача в «Лудки» не мешает раздаче в «General». Никаких настроек
не нужно: просто пишите команды в нужной теме.

## Первый запуск

1. `npm install`
2. `npx wrangler login` — один раз, откроется браузер Cloudflare.
3. В Telegram у [@BotFather](https://t.me/BotFather): `/newbot` → токен.
4. `./deploy.sh` — создаст `.secrets`, впиши туда токен, запусти ещё раз.
5. Добавить бота в группу и написать `/ludoman_spin`.

## Обновление

Поменять `BOT_VERSION` в `src/table.js`, `./deploy.sh`. Проверка в чате —
`/bot_version`.

## Локальный прогон без Telegram

```bash
node test/mock_telegram.mjs &      # фейковый Telegram на :8081
printf 'BOT_TOKEN=test\nWEBHOOK_SECRET=s3cret\nTELEGRAM_API=http://127.0.0.1:8081\n' > .dev.vars
npx wrangler dev                   # worker на :8787
```

Дальше слать апдейты curl'ом на `http://127.0.0.1:8787/` с заголовком
`X-Telegram-Bot-Api-Secret-Token: s3cret`; ответы бота пишутся в
`test/mock_telegram.log`.
