# Ludoman Spin — покерный бот для Telegram

Техасский холдем прямо в групповом чате. Работает на Google Apps Script
(бесплатно, без сервера), деплой через clasp.

## Как играть

| Команда | Что делает |
|---|---|
| `/ludoman_spin` | Открывает стол: 30 секунд на вход по кнопке «Присоединиться» |
| `/ludoman_top` | Рейтинг чата по фишкам |
| `/ludoman_cancel` | Отменить текущую раздачу (анте возвращается) |
| `/bot_version` | Какая версия задеплоена |

После сбора всем раздаётся по 2 карты. Свои карты каждый смотрит кнопкой
«👀 Мои карты» — Telegram показывает их всплывающим окном только нажавшему.
Флоп, тёрн и ривер открываются кнопкой прямо в том же сообщении, затем
вскрытие: бот сравнивает комбинации и отдаёт банк победителю (ничья — делит).

Фишки: у новичка 1000, взнос за раздачу 100, кто просадил всё — получает новый
стек. Ставок по улицам нет: каждая раздача — это «спин» до вскрытия.

## Файлы

- `Poker.js` — колода и оценка комбинаций (чистая логика, без Telegram)
- `Bot.js` — обработка апдейтов Telegram, лобби, раздача, хранение состояния
- `Config.example.js` — шаблон секретов; реальный `Config.js` в git не попадает
- `appsscript.json` — манифест Apps Script (веб-приложение, права)
- `deploy.sh` — заливка кода, обновление деплоя, регистрация вебхука
- `test/run_tests.js` — локальные тесты: `node test/run_tests.js`

## Первый запуск

1. В Telegram у [@BotFather](https://t.me/BotFather): `/newbot` → получить токен.
   Там же `/setprivacy` → Disable не нужен: бот читает только команды и кнопки.
2. `./deploy.sh` — создаст `Config.js`; впиши в него токен и запусти ещё раз.
3. Один раз открыть редактор (`clasp open-script`), запустить функцию
   `setupTelegramWebhook` и разрешить доступ — так Google выдаёт скрипту права
   на запросы в Telegram и таймеры.
4. Добавить бота в группу и написать `/ludoman_spin`.

## Обновление

Поменять `BOT_VERSION` в `Bot.js`, прогнать тесты, `./deploy.sh`.
Проверка в чате — `/bot_version`.

## Как устроен таймер на 30 секунд

Apps Script не умеет ждать внутри запроса, поэтому лобби хранит дедлайн, а
раздачу запускает либо одноразовый триггер (срабатывает через 30–60 секунд,
точность платформы — до минуты), либо первое же нажатие/команда после дедлайна.
